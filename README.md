# Overview

As a software engineer I feel it is important to be continuously learning. To that goal I am attempting to learn Android Studio which I have no previous experience.

The app that I am attempting to build is a simple note app. It is geared toward travel notes. At this poit it is not quite working.
The idea is that the user would tap on a plus sign to add a note. The Note would be saved in a Room data base. The app would list
the notes in individual cards. In each is the option to update or delete the note.

The purpose of creating this app is so that when on vacation or other travels the user could jot down notes about thier trip.
With notes I would like to add the capability of saving pictures to the notes so that the user has notes to tie to their picture.
